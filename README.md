# Emoji-Spinner

A small, lightweight emoji spinner built with plain HTML, CSS and JavaScript.

## Demo

Open `index.html` in your browser to see the spinner in action. No build step or dependencies required — just a static page.


## Features

- Smooth CSS-based animation
- Pure HTML/CSS/JS (no frameworks)
- Easy to customize emojis, size, speed and colors


## Usage

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Emoji-Spinner.git

2. Open `index.html` in any modern web browser.

3. To change the emoji or speed, open `index.html` and `styles.css` and edit the markup and CSS variables.


## Customization

- Emoji: replace the emoji characters in the HTML where the spinner items are defined.
- Size: edit the CSS rules (width/height, font-size) in `styles.css`.
- Speed: adjust the animation-duration in `styles.css`.


## Files

- `index.html` — demo and markup
- `styles.css` — styles and animation
- `script.js` — optional JS (if present) for extra behavior
